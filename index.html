OnAir
Product preview

Broadcast overlays for collegiate esports, run by one operator.

OnAir is a desktop tool for a school's stream operator. It puts team names, logos, the series score and live match graphics on the school's stream through OBS, and keeps them right while the match is played.

Built on Overwolf ElectronWorks with OBSWindows

One window for the operator

The operator sets up the two teams and the series, checks that everything is connected, and goes live. During the match OnAir keeps the overlay in step with the game, and the operator can swap sides, show a timeout or correct a score.

These two pictures show the new design of the operator window, which is in development. The tool is in use today with an earlier layout.

What OnAir reads, and what it does not do

For VALORANT, OnAir reads match information through Overwolf's game events on the tournament observer's PC. It does not use the Riot web API.

Read from the game

  • Match and map: start and end, map, game mode, match score.
  • Rounds: round number, round phase and round result.
  • Players the observer sees: name, team, agent, health, ability and ultimate status, credits, and the scoreboard.
  • Spike: planted, defused, detonated.
  • Kill feed and which player the observer is watching.

Never

  • Shown to players. The overlay is on the broadcast only and gives no in-game advantage.
  • Sent to an outside server. Everything stays on the stream PC and goes out only as the picture on the stream.
  • Kept as player statistics. No profiles, rankings, ratings or scouting.
  • Placed over the game for a player. There is no in-game window and no advertising.

How it fits together

Status

OnAir is in use today on live collegiate esports broadcasts and is being prepared for more college programs. Alongside VALORANT it runs overlays for other titles a program broadcasts.
